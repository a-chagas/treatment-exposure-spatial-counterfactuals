# Licensing note

## Source data

The processed monitoring and ULEZ boundary files included under `data/` are derived from sources published under the UK Open Government Licence version 2.0 (OGL v2.0):

- London Air Quality Network / Environmental Research Group, Imperial College London;
- Greater London Authority / Transport for London ULEZ boundary datasets from the London Datastore.

OGL v2.0 permits copying, distribution, transmission, and adaptation subject to attribution and the other licence conditions. Source-specific attribution language is documented in `data/README_data.md`.

## Repository code

The software licence for the R code must be stated separately from the source-data licence. Add the selected software licence as the top-level `LICENSE` file before public release. The data licence does not automatically license the repository code.
